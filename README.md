# NovaAgent

Aplicación de escritorio con agentes de IA locales para Windows.

## Descarga

Los archivos listos para usar están en la pestaña **Actions** de este repositorio:

1. Ve a la pestaña **Actions**
2. Haz clic en la ejecución más reciente (la primera de la lista)
3. En la parte inferior de la página, en **Artifacts**, descarga:
   - `NovaAgent-Windows-Installer` - Instalador con asistente (recomendado)
   - `NovaAgent-Portable` - Versión portable sin instalación
   - `NovaAgent-Windows-Exe` - Ejecutable suelto

## Instalación

### Opción A: Instalador (recomendado)
1. Descarga `NovaAgent-Setup-1.0.0.exe`
2. Haz doble clic
3. Sigue las instrucciones del asistente
4. NovaAgent aparecerá en tu escritorio

### Opción B: Portable
1. Descarga `NovaAgent-Portable.zip`
2. Descomprime donde quieras
3. Haz doble clic en `NovaAgent.exe`

## Primer uso

La primera vez que abras NovaAgent te pedirá descargar un modelo de IA.
Esto es normal. Los modelos pesan varios GB y se descargan una sola vez.
Después de la descarga, NovaAgent funciona **sin conexión a Internet**.

## Requisitos

- Windows 10 o superior (64 bits)
- 8 GB de RAM mínimo (16 GB recomendado)
- (Opcional) GPU NVIDIA para mayor velocidad

## Desinstalación

- Configuración de Windows > Aplicaciones > NovaAgent > Desinstalar

## Características

- Motor de IA local (llama.cpp, sin Ollama)
- Interfaz gráfica moderna
- Modelado 3D, Roblox Studio, investigación web
- Aprendizaje de habilidades
- Modo offline tras descargar el modelo
